# wavewait v1.0.0

**Released:** 2026-11-07 · **Commit:** tag `v1.0.0` · **Previous:** first release (history up to v0.1.4 squashed)

## What it does


Cycle-level stall profile of any gfx1100 kernel (hipcc, Mojo, hand asm) from a real SQTT thread trace
on the 7900 XTX, through a KFD-direct runtime. Shows, per instruction, how many cycles each wave
waited before it issued.

```
                    run_hsaco.py                       wavewait (Mojo)
k.hsaco ──► KFD-direct launcher   ──► sqtt-capture ──► profile.pkl ──► per-pc table
           (ELF swapped in, hidden     (SQTT,                       (llvm-objdump pc map,
            kernargs filled)            WGP 3 pinned)                  waves walked by packet)
```

## Highlights

- New home: github.com/amarbarosys/wavewait. Old amarbaro/wavewait URLs redirect.
- No third-party ML framework needed: own HIP launcher, assembly probes, frozen decode tables.

## Changes

### Added
- `tools/run_hsaco`: HIP kernel launcher in Mojo (dlopen libamdhip64), checks every input before HIP.
- `probes/*.s`: 14 RDNA3 probes as gfx1100 assembly, one `probe.inc`, `build.sh`, `verify.sh` against golden bytes.
- `tools/pcmap.awk`: pc map from llvm-objdump, POSIX awk.
### Changed
- License: Apache-2.0 (was PolyForm Noncommercial 1.0.0). Commercial use is now free; NOTICE names the holder.
- `src/sqtt_table.mojo` is the frozen source of truth for the SQTT layout 3 tables.
- Capture is rocprofv3 ATT only (`tools/from-att.sh`, `tools/att-capture.sh`).
- History squashed to one commit; old tags and releases removed.
### Removed
- Pickled-profile input (`.pkl`), `tools/export.py`, `tools/gen_table.py`, `tools/oracle_counts.py`, `tools/run_hsaco.py`, `tools/sqtt-capture`, `wgp-probe.patch`, Python probe builders.
