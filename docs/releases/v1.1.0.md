## What it does

<!-- Stable description of the program. Carried forward from the previous note; edit only when the product itself changes.
     3 to 6 lines: what it is, who uses it, where it runs (URL/port/binary), how to start it. -->
Cycle-level stall profile of any gfx1100 kernel (hipcc, Mojo, hand asm) from a real SQTT thread trace
on the 7900 XTX, through a KFD-direct runtime. Shows, per instruction, how many cycles each wave
waited before it issued.

```
                    run_hsaco.py                       wavewait (Mojo)
k.hsaco ──► KFD-direct launcher   ──► sqtt-capture ──► profile.pkl ──► per-pc table
           (ELF swapped in, hidden     (SQTT,                       (llvm-objdump pc map,
            kernargs filled)            WGP 3 pinned)                  waves walked by packet)
```

## Highlights

<!-- 1 to 5 bullets a user would notice. Lead with the benefit, not the implementation. -->
- `wavewait DIR --causes --gui`: the cycles by cause and the costliest rows in a window (picture in the README).
- `tools/comfy-prof.sh`: one command from any ComfyUI API graph to a per-node kernel-class table.
- `--by-class --watts W --tok-s T`: each instruction class's share of the board watts and mJ per token.

## Changes

### Added
- `--gui`: execs `build/wavewait-gui` (`src/gui.mojo`, imkit) with the same arguments; `check.sh` builds it only when
  `../mojo-imkit` exists, so the CLI never needs imkit.
- `tools/comfy-prof.sh` and `tools/kclass.sh`: resident ComfyUI server under rocprofv3 `--kernel-trace`, per node (or
  sampler step) wall, busy union, dispatches and kernel time by class.
- `--by-class --watts W --tok-s T`: W and mJ/tok per instruction class (cycle-share model, an upper bound).
### Changed
- Build: `max==26.7.0` in pixi for the window's GPU compose.
### Fixed
- `tools/comfy-trace.sh` passes `COMFYUI_ENABLE_MIOPEN` into the gpu-wait job.

## Known limits

<!-- Honest list: slow paths, unsupported cases, flaky upstreams, anything UNVERIFIED. -->
- `--gui` needs a GPU, SDL3 and `mojo-imkit` next to the repo at build time; without imkit `--gui` says so and exits 2.
- The `--watts` split is a cycle-share model, not a measured per-class power.
- `probes/verify.sh` looks for clang and ld.lld in `/opt/rocm/llvm/bin` or `/usr/bin`; elsewhere set `LLVM=`.
